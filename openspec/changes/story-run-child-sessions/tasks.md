  *Relay the questions* instead of repeating

  The epic run still prints it once per report, before the first marked
  question.

  `failed at <step name>: ` followed by the step's reason, with the
  example `failed at build: tests fail on main`, instead of the literal
  `failed at <step name>: <reason>`. The existing check *an epic run's
  stop rule is written once* requires that literal once in the skill,
  in *A stop in an epic run*. The report's form is unchanged.
