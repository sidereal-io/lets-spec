# Reader walkthrough results

Author walkthroughs, not human usability trials:
- Missing change and route: stop before propose; an existing change continues.
- Saved standard schema with a minimal route: keep standard; a new minimal route selects minimal.
- Failed or non-JSON state query: show its output and stop, without retrying.
- Unknown state without instruction: show the full output and stop.
- Archive folder alone: report archiving; the pull request establishes readiness.
- The shell example preserves the apostrophe and literal `$HOME` in one argument.
- Shaping may create its issue before the run claims it and creates a change branch.
