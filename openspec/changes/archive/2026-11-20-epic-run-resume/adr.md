## Review Summary

ADR review completed for this change. No decision in `design.md` needs a
record. D-A to D-I are skill text, tests and one new option on
`lets backlog ready`, all in this repository. A later change can rewrite
any of them without migrating data, config or a contract outside the
repository, and the specs state the behavior a reader needs.

The design follows three in-force records:

- [ADR-017](../../../docs/decisions/ADR-017-lets-go-reads-where-a-run-stands-from-git-and-github.md):
  a second epic run reads each story's progress from its branch and pull
  request, and keeps no log of its own (D-D, D-G).
- [ADR-021](../../../docs/decisions/ADR-021-where-an-outside-command-runs.md):
  ranking the started stories with the others is a shared rule, so it
  runs in `lets backlog ready` (D-A). The pull request reads and the base
  edit are single calls, so they stay in the skill (D-D, D-E).
- [ADR-025](../../../docs/decisions/ADR-025-an-item-key-is-opaque.md):
  `--started` takes keys, and a blocker in another repository never
  counts as met on the started path either (D-C).
