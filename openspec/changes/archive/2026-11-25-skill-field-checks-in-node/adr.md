## Review Summary

ADR review completed for this change. Two in-force records bear on it,
and the change follows both without changing them:

- [ADR-021: An outside command runs in lets code or in the skill, by how complex and portable it must be](../../../docs/decisions/ADR-021-where-an-outside-command-runs.md)
  is why `lets backlog` prints JSON for the skills to read. The new
  check keeps the fields and values the skills read in step with that
  output.
- [ADR-025: A backlog item is named by an opaque key that only its backlog provider reads](../../../docs/decisions/ADR-025-an-item-key-is-opaque.md)
  gives each item its `key` and `label`. The rewrite names them as the
  `key` field and the `label` field, and keeps reading them as the
  record says.

None of design.md's decisions needs a record of its own. Each lives in
test code in `tests/contracts/` or in a writing rule in this
repository's `AGENTS.md`, and a later story can change it cheaply: how
the help is parsed, which spans the check reads, the `next` word in
`texts.ts`, and where the rule is written. The rule that a check reads
its names from what a command prints is one of #308's Shared decisions,
not this change's.
