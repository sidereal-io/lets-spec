## Deviations Ledger

<!-- Dated notes on small departures from the plan, written during apply. Stop and ask the user about a large one. -->

- 2026-11-04, 2.1: the test "step instructions skip cli" went in 2.1, not 2.6. Adding `step` makes `pick` choose `cli` for step instructions, so that test failed as soon as 2.1 passed. For the same reason, the instructions tests of 2.6 pass when first written: they pin behaviour that 2.1 already gives.
- 2026-11-04, 2.2 to 2.5: the code of 2.1 already gives these behaviours, so their tests passed when first written. Each was checked instead by breaking the code it pins, such as the write-mode flags or the scrubbed environment, and seeing it fail.
- 2026-11-04, 2.4: the scenario "The CLI refuses the model for a step" and task 2.4 asked for a line starting `lets delegate: gpt/gpt-6-astra: ` on stderr when a later model answers. `lets` prints refusal lines only when every model is refused (`withModels` in `lets/src/delegate/lookup.ts`, and the `delegate-config` spec), for every resolver and command. Printing them on success would change that shared contract, which the design rules out. The scenario and the task now assert that codex runs first, claude second, and that the record names `claude`.
