## Deviations Ledger

- 1.2: `lets-go` joins two loops, not three: the exit 3 test, renamed to cover every skill that delegates to a subagent, and the rank-and-filter test. The third check that loops over delegating skills, the review skills' ranking and empty-options lines, names review-only wording. `lets-go` ranks and handles empty options as `lets-build`'s handoff does, so the new test checks those lines instead.
- 2.1: *Start* also runs `lets-build`'s *Import the glossary checkpoint* when *Claim*'s glossary preflight found owned edits. `lets-build` runs it at the top of *Propose*, which `lets-go` does not run in its own session, so without it a chore that owns glossary edits would lose them. It adds no check.
- 2.2: on exit 3, `lets-go` takes the subagent step only when the meta file names the prompt `lets` saved. Only the `subagent` resolver saves one. Exit 3 can also mean that a resolver which runs steps refused every model, and then no prompt is saved, so `lets-go` shows the meta file and stops.
