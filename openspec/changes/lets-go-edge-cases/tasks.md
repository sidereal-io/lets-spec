## 1. An explicit rule for each rare input

- [ ] 1.1 [medium] *Read the request* takes a leading or trailing `ask` or `recommend` as the level only when the rest of the request is a number or nothing. When the rest is words on the default branch, it asks the user, at either level and before *Start from an idea*, whether the word names the level or is part of the idea, showing both readings; on "part of the idea" the word stays in the idea and *Set the level* takes its next source. On another branch it asks nothing, because words stop the run there. `take it off, and keep it for` no longer stands alone. A check named `lets-go asks whether a level word beside an idea is the level` covers each case of *lets-go takes one issue number or an idea* (verify: `bats tests/skill-interfaces.bats -f "level word beside an idea"`)
- [ ] 1.2 [easy] On the default branch, an idea that holds no letter or digit, in any script, stops in *Read the request*: the run says that an idea needs at least one letter or digit, claims nothing and runs no step, before the discovery query and the title search. The overview row for *Read the request* names the stop in its *Stops when* cell. A check named `lets-go stops an idea with no letter or digit` reads `part_section 'Read the request'` and the overview row (verify: `bats tests/skill-interfaces.bats -f "no letter or digit"`)
- [ ] 1.3 [easy] `references/shape.md`'s *The shape step's name* says that *Read the request* has already stopped an idea with no letter or digit, so `<slug>` is never empty and no shape step is named `idea-`. A check named `the shape step's name is never idea- alone` reads that section (verify: `bats tests/skill-interfaces.bats -f "never idea- alone"`)
- [ ] 1.4 [medium] *Relay the questions* relays every question of a step as at `ask` from that step's sixth `needs-input` report in this run: it asks the user each one, shows the recommendation as the suggested answer, and writes the answer with no marker. It prints `Interactivity: ask for the rest of this step, because it asked for input five times.` once, before the first such question. A check named `lets-go limits a step's rounds at recommend` pins the line with `skill_says_once` and the sixth-report rule (verify: `bats tests/skill-interfaces.bats -f "limits a step's rounds"`)
- [ ] 1.5 [easy] *Relay the questions* says the round count is per step and per run, so a new run or another step starts again at none, and that the repeated-question stop still holds. The closing sentence `A step's rounds go on until its report is` links the limit. The check of 1.4 covers both sentences (verify: `bats tests/skill-interfaces.bats -f "limits a step's rounds"`)
- [ ] 1.6 [easy] *Enter the branch* step 5 sets `<schema>` from the `schema:` line of the first that exists: `openspec/changes/<name>/.openspec.yaml`, then the archive folder's `.openspec.yaml`, the folder whose whole name is `<YYYY-MM-DD>-<name>` in `openspec/changes/archive/`; otherwise the schema *Route* picked. A check named `an archived change keeps the schema it was built with` reads `part_section 'Enter the branch'` and checks the order of the three sources (verify: `bats tests/skill-interfaces.bats -f "keeps the schema it was built with"`)
- [ ] 1.7 [easy] The whole suite and the release build pass: every placeholder still has a row in the Placeholders table, every link resolves in the source and in both published flows, and new and reworded lines wrap at 72 columns (verify: `pnpm test && nix flake check`)
