## REMOVED Requirements

### Requirement: lets go level prints the default level
**Reason**: The interactivity level is renamed the question mode, so `lets go level` becomes `lets go questions` and `go.level` becomes `go.questions`.
**Migration**: Moved to *go-questions*, restated with the new names. Set `go.questions: ask` or `go.questions: auto` in place of `go.level`. A `go.level` key is now ignored.
