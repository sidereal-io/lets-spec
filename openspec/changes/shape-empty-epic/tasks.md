## Deviations Ledger

- **3.5: `git add` takes only the copied maps.** The task says
  `git -C <path> add -- <paths>`. After `git -C <path> rm -q -- <map>`,
  `git add` fails on that path ("pathspec did not match any files"),
  while `git commit -- <paths>` takes it. So the add takes
  `<copied paths>`, and the commit still takes every listed path. A
  bats test runs the commands on a repository with a modified, a new and
  a removed map.
- **3.5: the placeholder is `<map>`, not `<p>`.** `<p>` is a retired
  placeholder name that *lets-go gives each placeholder one meaning*
  forbids. `<map>`, `<copied paths>` and `<tracked paths>` have rows in
  the Placeholders table.
- **3.5: a removed map can be staged.** The removal case covers `D ` as
  well as ` D`, and the restore runs only when there are tracked paths,
  because `git restore` with no path fails.
- **3.5: the procedure returns Git's error.** A lets-go procedure never
  stops; *Enter the branch* stops on the error, as *A stop in an epic
  run* says.
