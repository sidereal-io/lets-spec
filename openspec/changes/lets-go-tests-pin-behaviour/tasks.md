## 1. The lets-go tests read the reference files and pin behaviour

Every task changes `tests/skill-interfaces.bats` only; the text of `skills/lets-go/SKILL.md` does not change. Fixture tests build a skills folder under `$BATS_TEST_TMPDIR`, so the helpers read their skills folder from a variable that defaults to `$repo/skills`.

- [x] 1.1 [medium] `skill_says <skill> <text>` reads the skill's `SKILL.md` and every `references/*.md` as one text with whitespace collapsed: a fixture test finds a string that wraps across two lines of a reference file, and another fails and names a string no file holds (verify: bats tests/skill-interfaces.bats -f 'skill_says') (✓ bats tests/skill-interfaces.bats -f 'skill_says' passed)
- [x] 1.2 [easy] A new `skill_does_not_say <skill> <text>` reads the same text and fails, naming the string, when any file holds it; it can match case-insensitively. A fixture test fails on a phrase that only a reference file holds (verify: bats tests/skill-interfaces.bats -f 'skill_does_not_say') (✓ bats tests/skill-interfaces.bats -f 'skill_does_not_say' passed)
