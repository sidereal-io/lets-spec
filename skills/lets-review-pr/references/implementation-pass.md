# Implementation pass lens

Add this lens to the common role prompt. Examine correctness, structure, connections and integration across the complete diff and necessary surrounding code at the same captured revision.

Trace concrete inputs, state transitions, failure paths and changed boundaries. Check whether callers, consumers, configuration, packaging and tests agree with the changed behavior. Assess structure where it creates a meaningful maintenance or correctness consequence, not a style preference. Follow recognizable domain meanings through representation mappings.

Give specific evidence and a plausible consequence for every concern; report coverage gaps, inaccessible context and execution limits honestly. Do not wait for contributor fixes, change files or execute target code to manufacture certainty. A clean result is legitimate when no substantive concern survives challenge.
